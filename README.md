# E-Continuity — археологический и методологический аудит

Этот репозиторий фиксирует воспроизводимый аудит переданного авторского корпуса E-Continuity (историческое название — Template E). Аудит не объявляет фреймворк научно валидированным и не заменяет внешнюю отраслевую рецензию.

## Текущий вывод

Содержательное ядро v2.3 реконструируется уверенно, но пакет ещё не готов к статусу «проверенного стандарта» или «Gold Master». Его сильная сторона — ясное различение сохранности объекта и восстановимости миссии. Главный дефицит — переход от концептуальной архитектуры к операционализированной методике: измеримые переменные, протокол оценки, воспроизводимость, калибровка шкал, прослеживаемые источники и независимая проверка.

## Карта репозитория

- `audit/ARCHAEOLOGICAL_AUDIT_RU.md` — происхождение, поколения, дубли и статус артефактов.
- `audit/SYSTEM_AND_METHODOLOGICAL_AUDIT_RU.md` — системный и методологический разбор.
- `audit/LINE_AUDIT_GUIDE_RU.md` — устройство полного построчного реестра.
- `audit/VISUAL_QA_RU.md` — визуальная проверка текущего unified PDF и ограничение DOCX‑проверки.
- `audit/ISSUES.csv` — нормализованный реестр замечаний и критерии закрытия.
- `audit/evidence/summary.json` — агрегированная статистика прохода без публикации текста корпуса.
- `tools/audit_archives.py` — воспроизводимый конвейер анализа ZIP/DOCX/PDF/TXT/MD.

## Воспроизведение

```powershell
$env:PYTHONUTF8='1'
python tools/audit_archives.py <каталог-с-ZIP> audit
```

Входные ZIP и детальные evidence-файлы (`inventory.csv`, хеш-группы, извлечённый текст, полный `line_audit.jsonl`) намеренно не публикуются в этой ревизии. Они сохранены локально для проверки, но содержат пути и производный текст авторского корпуса. Их публикация допустима только отдельным решением после определения публичности, лицензии и canonical release set.
