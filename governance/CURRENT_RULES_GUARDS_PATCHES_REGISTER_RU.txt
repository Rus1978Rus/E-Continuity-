4. PROJECT_WIDE_DOCUMENT_PROVENANCE_AND_ARTIFACT_RULE_v0_2
- Каждый важный документ должен иметь DOCUMENT_PROVENANCE_CARD.
- Content (содержимое) ≠ source (источник).
- Copy (копия) ≠ provenance (происхождение).
- Reconstruction (реконструкция) ≠ physical original (физический оригинал).
- Hash exists (хеш существует) ≠ hash verified (хеш проверен).
- LLM output (вывод ИИ) ≠ verified copy (проверенная копия).
- Не выдумывать hash (хеш).
- Для ZIP нужен manifest (манифест) и checksums (контрольные суммы), где возможно.

8. INTERFACE_TO_RECOVERABILITY_GUARD_v0_1
- Derived from INTERFACE_THEORY_OF_PERCEPTION_IMPORT_v0_1A.
- Core rule: Interface State (интерфейсное состояние) ≠ Recoverability State (проверенная восстановимость).
- Формула: Видимость сохранности ≠ доказанная восстановимость.
- Примеры: file opens (файл открывается) ≠ semantic recoverability (смысловая восстановимость);
  object looks intact (объект выглядит целым) ≠ dynamic recoverability (динамическая восстановимость);
  archive exists (архив есть) ≠ custody chain alive (цепочка ответственности жива);
  hash exists (хеш есть) ≠ hash verified (хеш проверен).
